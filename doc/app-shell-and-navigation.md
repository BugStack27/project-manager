# 壳层与导航 — 决策记录

> 状态：✅ 已验收（2026-10-21 ~ 2026-11-11）

## 1. 目标与范围

三栏壳层（左栏导航与项目 / 中区页面内容 / 右面板上下文）是全部页面的共同容器，本篇只记录壳层与导航层的既定契约。

- **做**：三栏宽度与收起、尺寸记忆、中区扁平化版式、五页共用顶部状态栏、项目内视图页签与返回导航、侧栏项目排序与「设置与数据」浮层、前端源码物理分模块。
- **不做**：页面内部内容与数据模型、右面板与弹窗的卡片样式（保持浮层语义）、CSS Modules 迁移、effect 时序重排、组件级单元测试（仅拖拽换算纯函数除外）。
- 相关文档：页面内容见 `doc/requirements-and-agent.md`、`doc/launch-and-runs.md`、`doc/changes-and-git-sync.md`、`doc/overview-and-statistics.md`；配色 token 见 `doc/theme-and-identity-colors.md`；快捷键与改键见 `doc/search-and-shortcuts.md`；前后端分层见 `doc/architecture-and-channels.md`。

## 2. 关键决策

### 2.1 壳层与布局

| 决策点 | 结论 | 理由 |
|---|---|---|
| 左栏收起形态 | 收成约 48px 图标窄栏（仅图标 + `title`），不收成 0 | 保留导航与项目的可点性，不引入二级浮层菜单 |
| 右面板 | 全局常驻的覆盖式抽屉，内容随页面变化（需求详情 / 运行日志 / 提交说明与改动内容）；点需求 / 日志 / 改动、进启动台或深链就地展开，关闭用内容首行的 ×、Esc 或点抽屉外，状态栏不放面板开关 | 统一壳层，页面内容不感知面板宽度；展开跟着内容走、关闭入口贴着内容，不用回页栏找开关 |
| 右面板开关移除（2026-11-11） | 状态栏不再渲染展开 / 关闭右面板的 chevron 开关；抽屉展开完全跟随内容，关闭用内容首行 × 或 Esc | 开关与「点内容即展开」重复，且总览 / 统计点开只是一片空壳；去掉后页栏右侧只留 IDE，少一个紧贴窗口系统按钮的误点区 |
| 点抽屉外自动收起（2026-11-11） | 抽屉展开时点它以外的区域即收起；但「点开 / 切换抽屉内容」的点击（列表行 / 日志 / 改动 / 深链 / 悬浮球）豁免，弹窗与命令面板盖在上面时不响应，拖拽（调宽 / 排序 / 选文本）松手合成的 click 也豁免 | 覆盖式抽屉应与浮层同一套「点外面即关」；豁免保证换内容不先关再开地闪、拖完宽不被误关 |
| 尺寸记忆 | 宽度与收起态存 `localStorage.pm.ui.layout`（`{leftW,leftCollapsed,rightW,rightCollapsed}`），左 180–360 / 右 240–560（宽屏上限随视口放宽到 45%，最多 900）；≤1100px 首屏默认收起右面板 | 刷新后保持；不存展开态与选中态，避免脏状态 |
| 选中态归属 | `{kind, sha, path}` 单一来源存 App，中区列表与右面板共同消费；`kind` 取 `working` / `commit-info` | 两侧高亮与来源一致；`commit-info` 是「提交说明 + 文件清单」的提交详情 |
| 分栏线 | 栏宽用内联值，分隔线由分隔条绘制，左栏不再自带常驻右边框与固定宽度 | 内联宽度与 CSS 固定宽度会互相打架 |
| 窄栏可读性 | 收起时只隐藏品牌文字、保留 logo 并纵向居中，导航与项目项补 `title` | 图标栏仍需表达语义 |

### 2.2 状态栏与扁平化

| 决策点 | 结论 | 理由 |
|---|---|---|
| 扁平化范围 | 中区信息条、列表、diff 视图、空态全部去卡片；右面板与弹窗保持卡片 | 消除中区卡片孤岛，浮层与右栏不在同一视觉语义内 |
| 中区布局 | `.wrap` 取消 `max-width` 与居中，内边距 `20px 16px 100px`，随窗口铺满 | 内容不再被 1000px 限宽截断 |
| 列表与 diff | 列表行 1px 分隔线直铺页面背景，保留 hover 淡灰底与选中左侧蓝条（行内边距 `12px 4px`）；diff 去外壳但正文保留浅灰底 | 提升信息密度；长 diff 需与页面正文分层 |
| 状态栏归属 | App 渲染一条 44px 条状栏，置于中区滚动容器内、`.wrap` 之外，铺满中区 | 各页共用一处结构，页面组件只留内容，且不受内容限宽 |
| 状态栏内容 | 标题（13px / 600，与右面板标题同层级）+ 页面图标（`PageBar` 的 `icon` 插槽，与左栏导航同套图标）+ 右侧全局动作 | 同一「你在哪」的概念不应有两套图形语言 |
| 按钮归置 | 全局动作（IDE）进状态栏右侧；页面级操作（如修改记录刷新）留在各自信息条 / 工具栏；右面板开合不做状态栏按钮，跟随内容就地展开 / 关闭 | 状态栏只放跨页共用动作，避免越变越杂 |
| 覆盖页面 | 需求中心 / 启动台 / 修改记录 / 总览 / 统计五页共用；统计页隐藏视图页签与 IDE 按钮，进入时自动收起右面板 | 统计页没有「当前项目视图」语义 |
| 圆角与配色 | 内容卡 / 面板卡 / 浮层卡统一收紧，控件圆角不动；中区背景提亮趋近纯白，左栏与右面板保持浅灰，描边与文字同步加深 | 只收内容卡显得不统一；提亮后需补层次与对比 |
| 视觉基线 | Apple HIG + inset grouped list；状态色为「深色文字 + 同色浅底」；反馈用 hover 提亮 + 按钮按下 `scale(.98)` | 首版冷灰卡片堆叠偏后台 dashboard；描边胶囊与卡片上浮已被否 |
| 导航角标 | 侧栏导航只剩「总览」「统计」；「总览」显示全部项目未完成需求数，「统计」无角标 | 常驻可见；项目内三视图入口改由中区页签承担 |
| 项目行状态灯 | 需求（未开始 / 进行中 / 待审核）、未提交改动、运行中三类灯，点灯直达对应视图，完整说明在行 tooltip | 数字角标只能表达规模，灯同时表达「有没有事」与「是哪类事」 |
| 项目行候选池角标（2026-11-11） | 候选池条数以**纯数字**角标挂在项目名后（描边胶囊、无圆点，min-width 18px 居中），仅 > 0 时出现；折叠侧栏隐藏，含义放在行 tooltip 与悬停提示「候选池 N 条（未确认，不派给 agent）」 | 候选池不是「有事要处理」，给它一盏灯会与未开始 / 进行中 / 待审核抢同一个位置并误导读者的优先级；但条数是「规模」，必须不点进项目就能看到，所以用角标。角标不写「候选」二字：项目行宽度有限，两个汉字等于把项目名再截短一截 |
| 未提交改动统计 | 口径为全部未归档项目中「工作区脏」的项目数；首屏 + 每 30s 轮询 + 修改记录页手动刷新，不跟随 5s 项目轮询 | 每项目起一次 git 进程，开销高于项目列表 |
| 项目行 `···` | 悬浮菜单（设置 / 在系统管理器中显示 / 在控制台中打开），外部点击 / Esc / 滚动关闭，近窗口底部自动上翻 | 提供定位项目目录的入口 |

### 2.3 页签切换与返回

| 决策点 | 结论 | 理由 |
|---|---|---|
| 页签形态 | 项目内三视图改用紧凑图标页签，不用分段控件或下划线页签 | 顶栏占宽最省（三项合计约 270px），不与 IDE 按钮抢空间 |
| 文字与标题 | 仅当前项展开名称，其余隐藏文字（名称由 tooltip 与 `aria-label` 补全）；标题位置由页签承担，不再重复显示当前页标题 | 三项常驻会挤占标题栏；当前项名称已表达所在页面 |
| 计数与灯 | 计数始终显示（含 0 与 0/N），灯只在「有事」时亮 | 数字表达规模、灯表达活跃，也避免页签宽度随状态跳动 |
| 切换 | 点击页签直接切换，当前项再点不重复导航 | 去掉两级操作，少一次点击 |
| 快捷键 | `cycleView` 作为第 5 条动作接入既有快捷键机制，默认 Ctrl / ⌘ + Tab，可改键、可恢复默认、参与冲突校验 | 不新增硬编码监听 |
| 循环顺序 | 按 `VIEWS` 顺序：需求中心 → 启动台 → 修改记录 → 需求中心 | 与页签排列一致，状态可预期 |
| 全局页行为 | 总览 / 统计不显示页签，Ctrl + Tab 不响应 | 两个页面没有「当前项目视图」语义 |
| 返回历史粒度 | 元素为 `{ page, pid }`，仅 `page` 变化入栈，返回动作本身不入栈 | 「返回上一页」而非「返回上一个项目」 |
| 历史深度 | 最多 50 条，超出丢弃最早一条 | 防无限增长 |
| 返回按钮 | 仅 `navStack` 非空时向 `PageBar` 传 `onBack`，标题前渲染按钮 | 首次进入总览无可返回 |
| 返回快捷键 | `Alt+←`（排除 ctrl/meta/shift）由 `useShortcuts` 统一分发；输入框 / 文本域 / 可编辑区 / 弹窗打开时不处理 | 避免干扰文字编辑，与其他快捷键共用改键机制 |
| 恢复范围 | 页面与项目一起恢复，右面板选中项（需求 / 日志 / 文件）不随历史恢复 | 历史只记录页面变化 |
| 失效目标 | 目标项目已归档 / 删除时退回总览并清空历史，`navBacking` 当场复位 | 目标页无从落地，且避免吞掉下一次正常入栈 |

### 2.4 侧栏交互

| 决策点 | 结论 | 理由 |
|---|---|---|
| 拖拽把手 | 只有左侧头像可拖，整行不拖 | 整行可拖让悬停抓手铺满列表，且破坏点击选中 |
| 参与范围 | 只重排未归档项目；收起成图标栏时禁用 | 收起后无可读目标 |
| 落点判定 | 按可见行纵向中点计算插入位置并画提示线，拖回原位不画线、不发请求 | 可预期，无实际移动不落库 |
| 持久化 | `reorderProjects(ids)` 只接收未归档项目的完整新顺序，数量不符由后端返回 409 `order_conflict` | 期间新建 / 归档时拒绝本次排序，界面刷新后重试 |
| 排序语义 | 不改 `updatedAt`、不写审计日志，归档项目在数组中原位不动 | 排列不是项目内容变更，审计只记业务写操作 |
| 落点换算 | 光标落在被拖项下半区时插入位置需减一，拖回原位不发请求 | 边界容易算错，集中在拖拽处理里一次写清 |
| 浮层形态与分组 | 「更多」改为「设置与数据」，点击向上弹分组浮层（数据：备份与恢复 / 数据文件；通知与集成：通知设置 / AI 接入；记录与关于：审计日志 / 检查更新 + 版本号），不在侧栏内展开 | 展开面板会把项目列表挤上去，入口变多后按用途分组更好找 |
| 浮层定位与关闭 | `position: fixed`，按触发按钮 `getBoundingClientRect` 算 `left / bottom` 并夹在视口内；点外部、Esc、窗口 resize 关闭，浮层内部与触发按钮不触发外部关闭 | 放进滚动 / `overflow` 容器会被裁切 |
| 收起态 | 侧栏收起时浮层关闭、入口文字与箭头隐藏只留图标，有新版本时红点在图标右上角 | 窄栏仍能看出「有更新」，但不再展开入口 |
| 更新提示 | `available` / `downloaded` 时入口与「检查更新」行都显示红点，版本号挂在行尾 | 不打开浮层也能看到有新版本；红点只表示可装 |
| 菜单语义 | 触发按钮 `aria-haspopup` / `aria-expanded`，浮层 `role="menu"`，每项 `role="menuitem"` | 浮层是菜单，不是普通弹窗 |

### 2.5 前端源码结构

| 决策点 | 结论 | 理由 |
|---|---|---|
| 拆分层级 | 只做物理搬移，行为零变化 | 早期 effect 顺序契约与多 state 强耦合，当轮抽 hook 会打散时序 |
| 目录结构 | 按角色建 `components/`、`lib/`、`styles/`；页面级文件仍平铺 | 新件有归属，旧页面不动 |
| 样式拆法 | 每个域一个文件，`index.css` 只放 `@import` 与注释，`responsive.css` 必须最后 import | `@import` 必须在文件最前，媒体查询需与基础规则同特异性后置覆盖 |
| 层叠验收 | 以「规则多重集一致 + 同选择器同属性最终胜出值一致」判定等价，允许规则换位置 | 换掉谁覆盖谁就是行为变化 |
| 图标与常量 | 直接改所有 import 来源，不做兼容 re-export | 避免两个真源 |
| 组件 key | `RightPanel` 迁移时原样保留 `key={selReq.id}` / `key={logCommand.id}` | 切换对象时重建组件是既有行为 |
| 领域 hook 化 | 抽 `useProjects`（列表 / 选中 / 刷新 / 排序 / 归档恢复删除联动）与 `useUpdater`（版本与更新动作），`useGit` 由 App 注入项目与导航依赖 | 更新状态只吃主进程 `pm:update` 推送，`App` 只做组装与接线 |
| 不变约束 | hook 化仍要求 effect 时序、消费型 effect 的「已处理」key、ref 守卫与轮询行为零变化 | 否则潜藏的重复请求与竞态会复现 |

## 4. 关键修正与教训

- **构建通过不等于行为等价**（`format.js` 漏 import 迁走的常量，`vite build` 不报错而首屏 `ReferenceError`）→ 迁出符号必须逐项做运行期冒烟。
- **CSS 层叠顺序是隐式契约，且 `@import` 之前的规则会让后续 import 被丢弃** → 保持 base 在前、媒体查询统一放最后一个 import，`index.css` 只允许 import 与注释。
- **组件提取不保留 `key` 会让切换对象时草稿与滚动状态串** → 迁移时原样带上 `key`。
- **只收内容卡圆角显得不统一，背景提亮后左栏文字与描边发灰** → 所有卡片统一收紧（控件不动），文字与描边一并加深。
- **统计文案放状态栏需进页才可见、项目行角标沿用「占用名额数」恒为 0** → 依次改为导航常驻角标、规模 + 活跃双字段角标，最终由三类状态灯取代。
- **状态色曾用描边胶囊、交互反馈曾用卡片上浮** → 统一为深色文字 + 同色浅底、hover 提亮 + 按钮 `scale(.98)`。
- **右面板与弹窗的卡片样式容易被连带误伤** → 去卡片只针对中区内容，改样式前先确认作用域。
- **已归档项目导致返回标记泄漏**（退回总览时 `page` 可能不变、effect 不执行）→ `navBacking` 必须当场复位。
- **只替换页签组件会漏掉宣传截图脚本的旧类名，改类名后「选中态留在上一项」也是假象** → 改交互结构后全局搜索旧类名，验证最终态前先禁用过渡（隐藏的内置浏览器会冻结 CSS 过渡）。
- **整行拖拽破坏点击选中** → 把手只留在头像上。
- **拖到自身下半区不等于移动** → 插入位置按 `insertAt === from + 1` 扣掉自身，落点不变时不发请求。
- **浮层放进侧栏容器会被裁切，收起侧栏时浮层不关则成为无主弹层** → fixed 定位并夹在视口内，收起时一并关闭。
- **排序不是业务事件，并发变更也不能覆盖** → 不写审计、不动 `updatedAt`，数量不符宁可 409 拒绝。
- **面板宽度内联值与残留常驻边框 / 固定宽度打架，左栏收起时曾把 logo 一并隐藏** → 移除常驻边框改由分隔条画线，收起时只隐藏品牌文字。

## 5. 已知边界

- 拖拽调宽走 pointer 事件 + capture，浏览器自动化无法模拟鼠标拖拽，端到端拖拽未验证；状态栏 sticky 与配色观感由用户自测。
- 左栏最窄 180、右面板 240–560（视口越宽上限越高，45% / 最多 900），超出由 `clampW` 夹回；布局只记忆宽度与收起态，不记忆展开分组与选中项。
- 视图页签仅覆盖项目内三视图；不支持反向循环（Shift + Ctrl + Tab），弹窗打开或焦点在输入控件时快捷键不触发。
- 页签文本按当前项伸缩，切换时宽度变化带来轻微布局跳动（已接受，换取更窄的常驻宽度）；tooltip 目前只含名称与计数。
- 返回历史仅存内存，重启 / 刷新后清空；只记录页面切换，不记录页内筛选等状态。
- 侧栏排序只作用于未归档项目之间，不支持键盘排序与触屏长按拖拽（依赖 HTML5 drag & drop），隐藏项不参与但保留槽位；排序期间项目集合变化以后端校验为准。
- 侧栏收起时不能排序、不能打开「设置与数据」浮层；浮层展开状态不持久化，resize / 点外部即关闭。
- 「在系统管理器中显示」依赖系统文件管理器（Windows explorer / macOS open / Linux xdg-open），路径不存在或非目录时回退错误码；未提交改动统计每项目起一次 git 进程，数据最长 30s 内可能过期。

## 6. 后续候选

- 前进导航（浏览器式 `Alt+→`）与页签反向循环 `Shift + Ctrl + Tab`；页签 tooltip 补充可随改键变化的快捷键提示。
- 键盘可操作的侧栏排序（上移 / 下移 / 置顶）、项目分组、记住浮层上次打开的分组。
- `App.jsx` 继续把加载器与轮询职责下沉到 hook，并以 effect 顺序清单作为契约；右面板需求详情单独扁平化。
