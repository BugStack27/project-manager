# 项目菜单复制路径 - 任务规划

## 1. 需求概述

侧栏与总览的项目行「更多操作」菜单里增加「复制路径」。一级菜单只保留一个入口，绝对路径与相对路径的选法放进二级菜单，不把两项平铺到一级菜单里。

相对路径口径：相对项目所在父目录，即只取项目文件夹名。以 `D:\job\peoject-manager` 为例，相对路径是 `peoject-manager`。

## 2. 需求澄清记录

| 问题 | 结论 | 来源 |
|---|---|---|
| 菜单层级怎么放 | 一级只有「复制路径」，绝对路径 / 相对路径作为二级菜单 | 需求正文 |
| 「相对路径」以哪个目录为基准 | 相对项目所在父目录，只取项目文件夹名；`D:\job\peoject-manager` → `peoject-manager` | 2026-11-23 用户回答 |

## 3. 任务列表

### 任务 1：ProjectMenu 增加复制路径入口与二级菜单

| 属性 | 值 |
|------|-----|
| **描述** | 在 `web/src/components/ProjectMenu.jsx` 的一级菜单中加入「复制路径」，悬停或点击展开二级菜单，二级菜单两项：绝对路径（`project.path` 原样）、相对路径（项目文件夹名）。二级菜单贴在一级菜单右侧弹出，空间不足时向左翻。 |
| **依赖关系** | 无 |
| **验收标准** | 侧栏与总览两处菜单都出现「复制路径 → 绝对路径 / 相对路径」；一级菜单行数只多一项；点选后菜单收起。 |

### 任务 2：复制成功 / 失败给到统一轻提示

| 属性 | 值 |
|------|-----|
| **描述** | `ProjectMenu` 新增 `onNotify` 入参，复制成功提示「已复制绝对路径 / 相对路径」，失败提示「复制失败，请手动选择文本复制」。`App.jsx` 把现有的 `notify` 通过 `Sidebar`、`OverviewPage` 传下来。 |
| **依赖关系** | 依赖任务 1 的菜单项 |
| **验收标准** | 复制后底部出现 Toast；剪贴板内容与选项一致。 |

### 任务 3：二级菜单样式与验证

| 属性 | 值 |
|------|-----|
| **描述** | 在 `web/src/styles/sidebar.css` 补齐二级菜单样式（父项右箭头、飞出层与主菜单同一套底色 / 阴影）。执行 `npm run build` 与 `npm run check` 验证，并用界面确认交互。 |
| **依赖关系** | 依赖任务 1 |
| **验收标准** | `npm run build` 通过；二级菜单不压出视口，悬停切换顺滑，点击后收起。 |

## 4. 执行顺序

任务 1 → 任务 2 → 任务 3。三项同一改动链，按顺序一次完成。
