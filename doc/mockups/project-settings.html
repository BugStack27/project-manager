设计稿

设计说明

延续现有视觉体系，重点解决层级、扫读与保存反馈。

1
项目身份置顶头像、名称、路径常驻头部，不用先进「基础」才能确认改的是哪个项目。
2
左栏带计数与影响摘要条目数量直接可见；「生效范围」说明这些配置会影响几条命令、几条规则会被 Agent 读到。
3
两种浏览方式分区切换适合逐项维护；连续滚动适合一次检查全部配置。工具条可切。
4
环境变量按账本排KEY / 值 / 生效范围一屏对齐，支持批量粘贴，减少逐条新建。
5
规则有编号与生效态停用的规则整卡降权并标「不会下发」，避免误以为已生效。
6
保存状态常驻条目自动保存，底部持续显示「所有更改已保存 + 时间」，基础区仍保留显式保存。
已落地：正式版本采用「连续滚动 + 左栏锚点」，分区切换仅作为设计备选保留在这份稿子里；规则正文已支持 Markdown 与 {UseSkill:x}。按评审意见，正式版去掉了字段旁的解释性小字与底部提示卡，改用状态 chip、计数和占位符表达。
