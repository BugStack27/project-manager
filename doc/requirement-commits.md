# 关联需求与提交 - 任务规划

## 1. 需求概述

把「需求」和「提交」连起来：需求端记录提交 hash。凡是带着需求上下文发生的提交（修改记录页的提交弹窗、验收时的「提交并推送」、手机端验收的自动提交），成功后都自动把本次新提交的 hash 记到那条需求上；需求详情新增「关联提交」区，按时间倒序列出短 hash、提交说明与时间，点「查看改动」跳到修改记录的该提交详情，看到当时的文件清单与 diff。

只记本次真正产生的提交：没有新改动（只推送已有提交）时不写任何 hash。

## 2. 需求澄清记录

| 问题 | 结论 | 来源 |
|---|---|---|
| 无新提交、只推送已有提交时，要不要把当前 HEAD 记到需求上 | 不记；只记本次新产生的提交，没有新提交就不记 | 2026-11-23 用户回答 |
| 关联入口范围 | 三条带需求上下文的提交路径都要关联：修改记录页提交弹窗（无论是否勾选自动审核）、验收时提交并推送、手机端验收自动提交 | 需求正文 + 实现口径 |
| 记录形态 | 每条需求保存一个提交列表（sha / 短 sha / 提交说明 / 时间），最多 20 条、按 sha 去重 | 实现口径：同一需求可能多轮交付 |

## 3. 任务列表

### 任务 1：需求记录提交 hash 的数据层

| 属性 | 值 |
|------|-----|
| **描述** | `electron/services/domain/requirements.js` 新增 `linkRequirementCommit({ rid, projectId, sha, subject })`：校验 sha 形状与需求归属，按 sha 去重后写入 `requirement.commits`（倒序、上限 20），不移动 `updatedAt`，记审计事件 `requirement.commit_linked`。`views.js` 的 `reqView` 下发 `commits`。 |
| **依赖关系** | 无 |
| **验收标准** | 直接调用可写入并去重；需求不属于该项目时报 400；`reqView.commits` 含 sha / shortSha / subject / at。 |

### 任务 2：三条提交路径自动关联

| 属性 | 值 |
|------|-----|
| **描述** | `changes.gitCommit` 接受可选 `requirementId`，提交成功拿到 sha 后调用 `linkRequirementCommit`（失败只记日志，不影响提交结果）。桌面端提交弹窗与验收入口把需求 id 传进 `gitCommit`；手机端 `commitAndPushApproved` 同样传 `r.id`。 |
| **依赖关系** | 依赖任务 1 |
| **验收标准** | 三种入口提交后需求都出现该提交；普通提交（无需求上下文）不写；`nothing_to_commit` 时不写。 |

### 任务 3：需求详情「关联提交」区与跳转

| 属性 | 值 |
|------|-----|
| **描述** | `RequirementDetail.jsx` 在验收区之后、往返记录之前新增「关联提交」区：短 hash、提交说明、时间 + 「查看改动」；点击走 `gotoProject(project, 'changes', { commitSha })` 打开修改记录并选中该提交。补样式与审计事件文案。 |
| **依赖关系** | 依赖任务 1、2 |
| **验收标准** | 有提交时显示、无提交时不占位；点击能跳到修改记录并打开该提交详情；`npm run check` / `npm run build` 通过。 |

## 4. 执行顺序

任务 1 → 任务 2 → 任务 3。数据层先落地，提交路径接上，最后是界面呈现；一次改动链完成。

## 5. 验证

- `npm run check`、`npm run build` 通过。
- 领域层脚本（临时数据目录 + 临时 git 仓库）：带需求 id 提交后关联 1 条且 sha 与 HEAD 一致；无改动提交返回 `nothing_to_commit` 且不新增；同一 sha 重复写入判 duplicate；非法 sha 400 `bad_sha`；跨项目关联 400 `bad_project`；普通提交不关联；22 条后按上限保留 20 条、最新在前；审计事件 `requirement.commit_linked` 正常落库。
- 界面冒烟（演示数据桥 + 无头 Edge CDP）：需求详情「关联提交」区显示短 hash / 说明 / 时间 / 查看改动；点击后跳到修改记录并打开该提交详情（`.gview-src` 为对应短 hash）。
